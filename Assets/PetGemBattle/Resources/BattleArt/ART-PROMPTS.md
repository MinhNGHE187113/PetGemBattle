# Battle art manifest

Created with the built-in image generation tool for this project. Four characters use transparent PNG backgrounds; the arena is opaque. Runtime loads them from Resources/BattleArt. No images were extracted from the reference screenshot.

The following are concise descriptions of the generation prompts, rather than verbatim tool-call transcripts.

| File | Prompt description |
| --- | --- |
| FireDragon.png | Original fantasy fire dragon warrior, crimson scales and ornate gold armor, fiery glaive, full body, facing right, strong readable silhouette, polished hand-painted 2D game art, isolated transparent background, no text or UI |
| FireDragonEvolved.png | Evolved form of the fire dragon warrior, more powerful gold/crimson armor, expanded fiery wings and weapon, same right-facing identity, full body, transparent background |
| ThunderFrost.png | Original thunder/ice guardian chimera, white and silver fur/armor, cyan crystal accents and electricity, quadruped stance facing left, full body, polished fantasy 2D battle sprite, transparent background |
| ThunderFrostEvolved.png | Evolved thunder/ice guardian, grander silver armor, broad crystalline wings and luminous cyan accents, retain left-facing identity, full body, transparent background |
| TempleArena.png | Wide painterly fantasy arena in an ancient jade forest temple, moss-covered stone architecture and atmospheric light, open central combat area, no characters, board, text or interface |

Character PNGs are single illustrations per form. PetPresentation adds motion, aura, attack, hit, evolution and result effects in Unity. A future skeletal rig or frame animation can replace this presentation without changing the combat model.
